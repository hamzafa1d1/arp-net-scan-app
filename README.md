# ARP Network Scanning Lab

A Python experiment for local network observation and ARP scanning. Source lives under `netwatch/`, with supporting `scraper.py` and `test_run.sh` files.

## Status

Learning experiment with no verified supported installation or platform matrix. Inspect the scripts and their dependencies before running. Use only on networks you own or are authorized to assess.

No scan coverage, detection accuracy or production-monitoring claim is made. Document a tested setup and example output before treating this as a maintained utility.
